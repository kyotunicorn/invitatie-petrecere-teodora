# invitatie-petrecere-teodora
O invitatie digitala in care:  1. persoana primește un link; 2. deschide linkul; 3. apare un ecran cu „Ai primit o invitație… 💌”; 4. apasă „Deschide invitația”; 5. apare fotografia + „ȘȘȘT! E SURPRIZĂ!” + toate detaliile; 6. eventual are și confetti/animație și muzică 🎀🎂✨
